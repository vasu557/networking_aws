The object storage available in aws is known  as S3
Simple storage service (s3) - 
the main advantage of s3 is unlimited storage. (where block storage is upto 16TB(16000 gb) )
inward - to s3 free (uploading)
outward - from s3 charged(downloading)

s3 -is built for different purposes. 
   so we have different  storage tiers. - unlimited 
STORAGE TIERS : 
s3 standard  - daily storage needs (instantly data needed)
s3 IA(infrequently accessing the data - less charge )
 s3 one zone - IA (even less charge)
s3 glacier - very infrequently accessing the data like once or twice in a year ) - very less expensive
                   but it take more time to access - nearly 2hrs.
s3 glacier deep archive - 5hrs

==>apolo uses s3 standard ans s3 glacier
s3 standard - for instantly access of patients data and
s3 glacier - for dataset.

bucket versioning : 
                    bucket versioning is known as
        =>I created 1 bucket and i had uploaded 1 object(file)  in  that bucket. - (original file)
        =>after enabling the bucket versioning that uploaded object will be saved as one version.
               If i am not satisfied with that object then i can edit that object and reuploaded it.(edited file)
         =>here newly uploaded object is another version.(current version)
          =>old version is known as null.
         => here the advantage is if u want go 1st uploaded object(original file) then u can simply permanently delete the newly edited file
             then u can  get the old edited file by copying the url (static host website/object url)
process of bucket versioning  :
1) create one bucket and give permissions to that bucket.
2)upload  1 file in that bucket. by add files
3)make that objects public. 
            =>  goto that file and copy the object url - u will get the uploaded file.
                      or
